Cards

Four alternatives to the current layout (left), all on the blurred town with Exit top right. Each tries to make the screen feel better, show more at a glance or need fewer taps. Everything is tappable: cards open their choices, topic chips talk, Back returns. The bar changes the character and how many cards there are.

  • Name and hearts bar: the current layout, A and C keep it exactly as wide as the first card. B stretches it across the whole grid as a heading. D uses the bust's width, since a card there is too narrow for a name.
  • No blur filters on glass (the game switches those off for smooth scrolling), so translucent cards are a plain see-through fill.
